# Чибик-спасатель (React + TypeScript)

Интерактивный обучающий веб-сервис для школьников по оказанию первой помощи. 
Проект создан в рамках курса по интернет-программированию.

## Лабораторная работа №2: Переход на React и TypeScript
В ходе второй лабораторной работы проект был переписан с использованием:
- **React** (компонентный подход)
- **TypeScript** (строгая типизация данных)
- **React Router** (маршрутизация между страницами)
- **Vite** (сборщик проекта)

## Реализованный функционал (на данный момент):
- Разделение интерфейса на логические компоненты (Header, Sidebar, SituationList и т.д.).
- Маршрутизация: Главная, Каталог, Категории, Урок, О проекте, Форма.
- Имитация загрузки данных с сервера (использование `useEffect` и состояния `loading`).
- Поиск по урокам на главной странице.
- Валидация формы обратной связи.
- Адаптивная верстка.

## Как запустить локально:
1. Установить зависимости: `npm install`
2. Запустить сервер: `npm run dev`
3. Открыть в браузере: `http://localhost:5173`
