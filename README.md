# Чибик-спасатель

Интерактивный обучающий веб-сервис для школьников по оказанию первой помощи. 
Проект создан в рамках курса по интернет-программированию.

## Описание
Сайт помогает изучать правила оказания первой помощи в игровой форме. Пользователь может выбрать ситуацию из каталога (порез, ожог, перелом и т.д.), найти нужную тему через поиск и посмотреть пошаговую инструкцию в модальном окне. Также на сайте есть форма для предложения новых ситуаций.

## Стек технологий (Лабораторная работа №1)
- HTML5 (семантическая верстка)
- CSS3 (Grid, Flexbox, адаптивность, медиазапросы)
- JavaScript (ES6, работа с DOM, события, массивы объектов)

## Реализованный функционал
- Адаптивная верстка (корректно отображается на ПК и мобильных устройствах).
- Вывод карточек ситуаций из JS-массива (минимум 5 записей).
- Поиск ситуаций по названию в реальном времени.
- Модальное окно с пошаговой инструкцией.
- Клиентская валидация формы обратной связи (проверка имени, email, категории, описания и чекбокса).

## Как запустить
1. Скачайте проект (или склонируйте репозиторий).
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge).
3. Сервер и база данных на данном этапе не требуются.

## Структура проекта
- `index.html` — главная страница
- `css/style.css` — стили
- `js/main.js` — логика приложения
